# A²LAB 목업 UI (AI 품질 예측 · 공정 최적화)

- `index.html`을 브라우저(Chrome·Edge)로 열면 바로 실행됩니다. 설치나 서버가 필요 없습니다.
- 로그인: 아이디 `admin` / 비밀번호 `aiq1234` (입력되어 있으니 [로그인]만 누르면 됩니다). 주소 끝에 `#auto`를 붙이면 로그인을 건너뜁니다.
- 우측 상단에서 한국어 / English / 日本語 전환, 다크·라이트 테마 전환
- 41개 화면: 통합 대시보드 1 + 4개 공정(태빙 TB · 오토솔더링 AS · 오토버싱 AB · 라미네이션 LM) × 10개 화면
  (실시간 품질 예측, 품질 예측 이력, 공정 최적값, AI 성능, 특성 중요도, 학습 데이터셋, 원본 데이터셋, 데이터 시각화, 원본 데이터 시각화, 상관관계 히트맵)
- 모든 화면이 가상 데이터로 동작: 조회·초기화, 정렬·페이지, 행 선택, 엑셀(CSV) 저장, 화면 도움말, NG 예측 알림, 화면 검색
- 날짜 입력: 직접 입력(20261029처럼 숫자만 쳐도 자동 변환) 또는 달력 버튼. 시작일이 종료일보다 늦거나 종료일이 오늘 이후면 안내가 나옵니다.
- 화면의 데이터·설비명은 모두 가상입니다. 고객사명과 서버 주소는 넣지 않았습니다.

## 다시 만들기
`python3 build.py` → `app.js` + `base.css` + `extra.css` + `tr/tr.json`(영·일 번역)을 합쳐 `index.html`을 만듭니다.
번역이 빠진 한글 문구는 `tr/missing.json`에 나옵니다.
